# On-Site Engagement & Context Retention UX Rules

## 1. Above-the-Fold Visitor Orientation
- **Primary H1 Heading**: Every page must have exactly one prominent `<h1>` tag stating the specific topic, product, or value proposition. Vague single-word titles (e.g. "Home", "Welcome") fail to orient visitors landing from search or AI assistant citations.
- **Context Retention**: Deep-linked visitors must confirm they have reached the right resource within 3 seconds of landing.

## 2. Machine-Readable Visual Content (`alt` Attributes)
- Information-rich diagrams, tables, infographics, and hero graphics must include descriptive `alt` text.
- If > 30% of image elements lack `alt` tags or use generic filenames ("banner.jpg", "image1.png"), key product facts are locked in non-text visual elements, preventing indexing by AI web crawlers.

## 3. Micro-Breadcrumbs & Anchor Jump-Links
- Provide explicit sticky section navigation and anchor jump-links (`#section-name`) so visitors referred by AI assistants can jump directly to relevant answer subsections.
